## 1. CRUX

The lecture is teaching a two-stage position-building decision, not a single buy signal: first, an entry gate (ADX + Vstop) to open a position in a core/compounder holding, and second, a separate, later-triggered pyramiding decision (parabolic SAR turning positive) to add to that position as it works — with Vstop turning negative reserved as the only exit signal, and RSI/OBV/comparative-strength offered only as optional probability boosters, not gates.

## 2. MECHANISM

- Buying has exactly "two basic conditions" in the instructor's own words: "First basic condition is that your ADX should be more than 20." and "So Vstop should also be positive." (WBPNW 00:04:54, WBPNW 00:05:00, WBPNW 00:05:07) — RSI is explicitly NOT one of these two basic buy conditions; it is introduced much later as an add-on.
- Pyramiding (averaging up / adding to a winner) is a distinct, later question from buying: "And to average up a particular security, what is the condition? Is that your parabolic SAR should also be giving an entry." (WBPNW 00:05:09-00:05:13)
- Parabolic SAR is repeatedly and explicitly forbidden from standalone use for buy or sell decisions — its only sanctioned use is as the pyramid-up trigger: "This can only be used for pyramiding up." and "Don't use this for selling or buying decisions standalone because this will lead to a lot of whipsaw movements and it will shake you out of stocks." (WBPNW 00:07:52-00:07:54)
- Exit is driven by Vstop turning negative, and parabolic SAR is explicitly excluded from that role too: "So this is purely meant for pyramiding up, not meant for as an exit signal." (WBPNW 00:10:12)
- The Vstop multiplier is not fixed at one value — default is "VSTOP with multiply length at 2" (WBPNW 00:04:11), but for a "compounder stock" with lower earnings volatility the instructor widens it: "now suppose if I was using 2.5X as we multiply, because I think this company has a lot of comp like it's a compounder stock" (WBPNW 00:12:41), and separately states "for compounder business use 2.5 as well where you think the earnings volatility is lesser" (WBPNW 00:15:17), implying a narrower/lower multiplier for cyclical names.
- Position sizing across pyramided tranches is bounded: build the target allocation over roughly two to four adds, not ten-plus — "I will actually suggest don't take allocations in more than three to four tranches" (WBPNW 00:10:16) — because a slow, many-tranche build-up compounds average cost if "there's something fundamentally weak in the company" (WBPNW 00:11:03).

- (b) No upper RSI bound exists in this specific lecture — worth stating plainly since the assignment brief flagged it as a hypothesis to check: WBPNW does not contain any "too hot to buy" RSI ceiling.
